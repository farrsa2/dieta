# data/

Esta carpeta contendrá los Markdown semanales aprobados que consume la web.

Archivos previstos para cada semana:

- `YYYYMMDD_SEMANAxx.md`
- `YYYYMMDD_SEMANAxx_CUADRO01_APROBADO.md`
- `YYYYMMDD_SEMANAxx_CUADRO02_APROBADO.md`
- `YYYYMMDD_SEMANAxx_COMPRA_APROBADA.md`

La web no debe modificar estos archivos: únicamente leerlos y mostrarlos.
